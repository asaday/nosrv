# Static site example

A handler-free nosrv App consisting only of `index.html`, CSS, and browser JavaScript. It demonstrates the zero-configuration static-site convention.

```bash
npm run dev
```

Open <http://127.0.0.1:8787/>. No `nosrv.yaml` or server-side entrypoint is required.

```bash
nosrv login --url http://127.0.0.1:3100
npm run deploy
```
